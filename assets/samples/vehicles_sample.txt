Field Descriptions:
==================
- Registration Plate: Vehicle registration number (e.g., BM23 X5A)
- Make: Vehicle manufacturer (BMW, Audi, Mercedes-Benz, etc.)
- Model: Vehicle model (X5, A4, C-Class, etc.)
- Year: Manufacturing year (2020, 2021, 2022, etc.)
- Color: Vehicle color (Black, White, Silver, etc.)
- Vehicle Type: Convertible, Coupe, Estate, Hatchback, Minibus, MPV, Pickup, Saloon, SUV
- Fuel Type: Petrol, Diesel, Electric, Hybrid
- Mileage: Current odometer reading in miles
- VIN: Vehicle Identification Number (17-character unique identifier)
- Horse Power: Engine power output in HP
- Fuel Efficiency: MPG for petrol/diesel, mi/kWh for electric
- Price: Rental price in £ (with insurance included)
- Price Period: monthly or weekly
- Initial Cost: Purchase/acquisition cost in £
- Vehicle Scheme: Rental or Rent To Buy
- Insurance Discount: Discount amount in £ when driver chooses without insurance (e.g., if price is £400/week and insurance discount is £50, driver pays £350/week without insurance)
- Available: True or False (boolean value)
- Vehicle Status: Available, Rented, Workshop, or Disabled
- Vehicle Group: Vehicle group identifier (usually 1 for default group)
- MOT Expiry Day: Day of MOT expiration (1-31)
- MOT Expiry Month: Month of MOT expiration (1-12)
- MOT Expiry Year: Year of MOT expiration (e.g., 25 for 2025)
- Telematics Link: GPS tracking URL
- Assigned Driver First Name: First name of the assigned driver (leave empty if no driver assigned)
- Assigned Driver Last Name: Last name of the assigned driver (leave empty if no driver assigned)

Instructions:
============
1. Copy the column headers and sample data above
2. Paste into Excel
3. Save as .xlsx format
4. Replace sample data with your actual vehicle information
5. Import using the vehicle import feature
